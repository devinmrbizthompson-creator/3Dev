# 3DEV Development — Landing Page

A responsive single-page landing site for Coach Devin “Mr. Biz” Thompson and the 3DEV 3Fold Practice System.

## Files

```text
3Dev/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── styles.css
    ├── js/
    │   └── main.js
    └── images/
        └── README.md
```

## Preview

Open `index.html` in a browser. Tailwind, Google Fonts, and QRCode.js load from CDNs, so those features need an internet connection. The contact form prepares an email using the visitor’s configured email app; it does not submit to a server or write to a spreadsheet.

## Publish with GitHub Pages

1. Open the repository **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. GitHub will show the published site URL in the Pages section after deployment.
