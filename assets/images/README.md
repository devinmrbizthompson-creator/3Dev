Place the 4 manga panels here in this folder.

Use these exact filenames so the manga reader can load them automatically:

- manga-page-01-02.jpg
- manga-page-03-04.jpg
- manga-page-05-06.jpg
- manga-page-07-08.jpg

These correspond to the four image slots used by the site inside `index.html`.

How to upload from GitHub:
1. Open the repo on GitHub.
2. Go to `assets/images/`.
3. Click Add file -> Upload files.
4. Upload the four images with the exact names above.
5. Refresh the page and the manga reader will display them.

If you want to use a different naming convention, update the matching `fileName` values in `index.html`.
